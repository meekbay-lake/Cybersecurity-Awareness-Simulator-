# 🛡️ Cybersecurity Awareness Simulator

A safe, offline, desktop educational demonstration tool written in Python (Tkinter) designed to demonstrate credential stuffing attacks, account lockout controls, and ransomware awareness.

> ⚠️ **DISCLAIMER:** This project is for **educational and training purposes only**. It runs completely offline, uses no actual networking, and makes no permanent changes to your computer or files.

---

## 📑 Features

- 🔐 **Realistic Sign-In GUI:** Material-style login UI resembling standard Google Accounts authentication.
- 🎯 **Account Lockout Control:** Visual attempt counter (max 3 failed attempts) showcasing brute-force mitigation.
- ☠️ **Ransomware Overlay Simulation:** Simulated lock screen with dynamic file list animation and 72-hour countdown timer.
- 🎓 **In-app Security Lessons:** Interactive educational window explaining credential stuffing, double extortion, and security best practices.

---

## 💻 Technical Requirements

- **Python Version:** Python 3.7+
- **Dependencies:** None (uses built-in `tkinter`, `time`, `random` libraries)
